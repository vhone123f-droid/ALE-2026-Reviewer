CONTENTS
- 300 original practice questions: 50 per subject
- Correct-answer explanation + explanation for every wrong option
- Mixed, unseen, wrong-answer, weak-area, bookmark, and subject modes
- Local progress storage and dark mode
- Automatic question-bank update engine
- Manual JSON update-pack import as fallback

IMPORTANT ABOUT “AUTOMATIC UPDATES”
The app can automatically CHECK and INSTALL a newer JSON bank whenever it opens, but a future bank must exist at a stable HTTPS update feed.

The default feed in this package is: ./updates/latest.json
That works automatically when the whole folder is hosted on an HTTPS website/PWA. To publish a future update, replace updates/latest.json so it points to the new bank file, and upload that new bank file.

If you simply open index.html as a local file on Android/iPhone, the quiz works offline, but phone browsers may block automatic web fetches from file:// pages. In that case use Updates > Import Update Pack.

EASIEST FULL AUTO-UPDATE SETUP
1. Upload this entire folder to any static HTTPS host (GitHub Pages, Netlify, Cloudflare Pages, etc.).
2. Open the hosted index.html on your phone.
3. Use Add to Home Screen / Install App.
4. Keep the same web address. When updates/latest.json announces a newer bank, the installed app downloads it automatically on launch.

UPDATE POLICY
Use official PRC TOS/advisories as the highest-priority source. Add original questions that reinforce high-weight competencies, calculations, and application/analysis. Do not use alleged leaked examination questions or unverified recall claims.
